# cinematic-hud-reel

A 22 s, 1920x1080, 30 fps sizzle reel for the fictional studio Nova Labs: HUD overlays, terminal micro-type, glow, camera punches and a logo finale, all timed to a 128 BPM grid. Built with HyperFrames (`hyperframes@0.8.143`) and GSAP. Silent: no audio is rendered, but every hit comes from one beat list, so a track can be added later.

## Render

```
pnpm run render      # builds index.html from content.json, renders out/cinematic-hud-reel.mp4 (about 1 min)
pnpm run check       # lint + layout + contrast gate
pnpm run still       # PNG snapshots into snapshots/ (see package.json to pass times)
```

Requires Node 22+, FFmpeg and Chrome. No dependencies to install: GSAP is vendored in `vendor/`, the headline font (Archivo 800, OFL) is in `fonts/`, and JetBrains Mono is fetched once by HyperFrames from Google Fonts and cached (needs network on the first run only).

`index.html` is generated by `scripts/build.mjs`; edit `content.json` or `src/`, not `index.html`.

## What to edit (`content.json`)

| Key | Effect |
|---|---|
| `brand` | wordmark text (`name`; the stroke font covers N O V A L B S only), tagline, handle, HUD system label |
| `colors` | background, accent, ice highlight, hit color (used on 2 moments), RGB-split colors |
| `format` | `bpm`, `durationSec`, `offsetFrames` (shift all hits), size and fps |
| `beats` | where each section starts, in beats (`hits`, `build`, `drop`, `finale`, `lock`, `riserFrom`) |
| `hitBeats` | every camera punch / flash / RGB split; drop beats get the heavy treatment |
| `hits`, `build`, `drop`, `cold`, `finale` | all on-screen copy and timing beats |
| `seed` | seeds decode glyphs, shake, stars and the logo fly-in |

Code layout: `src/theme.js` (tokens, beat grid, easing, seeded random), `src/hud.js` (persistent layers), `src/scenes/*.js` (one file per scene), `src/main.js` (frame driver).

## Notes

- Everything is a pure function of the frame number, with seeded randomness. Two renders on the author's machine matched visually (PSNR 49.6 dB or higher) but not byte for byte (GPU rasterization).
- Fonts: Archivo (OFL, see `fonts/Archivo-OFL.txt`) and JetBrains Mono (OFL). All brand names and the URL are fictional.
