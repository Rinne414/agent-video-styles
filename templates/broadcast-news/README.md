# broadcast-news

A 31 s tech-desk news bulletin: a colored panel and big numeral per story, kicker, headline, three spec lines, a BREAKING ticker and scanlines, voiced by en-US-GuyNeural. Style recipe: `skill/references/styles/broadcast-news.md` (experimental tier). Tool: HyperFrames `0.8.143` + GSAP `3.14.2`. All stories are fictional and labelled "Sample bulletin" on screen.

## Render

```
pnpm install
pnpm run render      # builds index.html, writes out/broadcast-news.mp4
pnpm run check       # lint + layout (see Known issues)
pnpm run still       # snapshots at 1,5,13,21,28 s
```

Needs Node 22+, pnpm, FFmpeg, Chrome. Fonts (Anton, Inter) come from `@fontsource/*` and are copied to `fonts/` by the build; GSAP is copied to `vendor/`. No network at render time.

## Edit

- `content.json`: story copy (kicker, headline, 3 spec lines, narration text), panel and numeral colors, ticker label and extra items, voice and rate, "Sample bulletin" tag, closing source line.
- `src/theme.mjs`: sizes, frame counts and easings from the style recipe.
- After changing narration text or voice, regenerate audio, then render:

```
pnpm run tts         # writes assets/audio/script.json, then runs skill/scripts/tts.py
pnpm run render
```

`index.html` is generated by `scripts/build.mjs` from `src/template.html`, `src/animate.js` and `assets/audio/timeline.json`; do not edit it by hand.

## Known issues

- `hyperframes check` reports 4 `text_occluded` errors for ticker text sliding under the BREAKING label (it is clipped by the ticker window; the render is correct). Render does not require `check` to pass.
