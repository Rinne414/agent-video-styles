# kinetic-typography

20 s vertical kinetic typography piece: five phrases, one word at a time on an empty stage, cut to a 120 BPM grid (silent), ending on a poster color-block finale. HyperFrames + GSAP.

## Render

    pnpm install
    pnpm run render      # builds index.html from content.json, writes out/kinetic-typography.mp4
    pnpm run still       # snapshots/ PNGs

## Edit

Everything lives in `content.json`: phrases and words, `keyIndex` (accent word), stage/type/accent colors, sizes, BPM, beat offset, motion frames, and the poster fields. `index.html` is generated by `scripts/build.mjs`; do not edit it by hand. Keep words at about 90% of frame width or less (size 360-400 for 6-letter words in Anton). Font: Anton via `@fontsource/anton` (copied to `fonts/`).
