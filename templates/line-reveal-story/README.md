# line-reveal-story

A 30 s silent picture-book short (1080x1920, 30 fps): a lighthouse keeper climbs the stairs at dusk, lights the lamp, and a small ship passes safely. Every scene is drawn in code from SVG paths. Line art sweeps in left to right, soft colour follows the same way, one caption sits in the empty paper above. Experimental style; all content is fictional sample content.

Tool: HyperFrames 0.8.143 + GSAP 3.14.2 (vendored). Font: Noto Serif (vendored woff2, OFL).

## Render

```
pnpm run check     # builds index.html, then lint/layout/contrast
pnpm run still     # snapshot PNGs in snapshots/
pnpm run render    # writes out/line-reveal-story.mp4 (composed 1088 wide, cropped to 1080: HyperFrames width bug)
```

Needs Node 22+, ffmpeg, Chrome. No network at render time.

## Edit

- `content.json`: palette, type sizes, stroke width, sweep timing, captions, scene lengths.
- `src/scenes/<id>.mjs`: the art of each scene (shape lists built from `src/parts.mjs`: lighthouse, keeper, ship, rocks, land, sea).
- `index.html` is generated by `scripts/build.mjs`; do not edit it by hand.

Adding a scene: create `src/scenes/<id>.mjs`, add `{ "id", "frames", "caption" }` to `content.json`.

## How it works

Every shape is one path used twice: filled in the colour layer, stroked in the line layer. Each layer sits under a feathered CSS mask whose edge position is a function of the frame. Strokes are knocked out where a later opaque fill covers them, so figures stand in front of scenery. Small loops (bob, sway, blink, drift) are driven by `sin(2*pi*frame/period)`.
